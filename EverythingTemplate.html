Introduction

This showcase project demonstrates all available display options for your portfolio. From full-width videos to before/after sliders, image grids, scroll-driven 360° videos, and slideshow variants—this page serves as a complete reference for building compelling project presentations.

Dev note: keep this file as a “menu” of layouts. Copy/paste blocks into your project pages and just swap paths, text, and years.

Display Option 1
Before/After Slider

The before/after slider allows visitors to compare two images by dragging a handle left or right. Perfect for showing transformations, AI enhancements, color grading comparisons, or design iterations. You can stack multiple sliders vertically for sequential comparisons.

Dev note: to add another slider, duplicate a <div class="ba">…</div> block. The JS + CSS automatically handle the drag. No extra script needed.

Display Option 2
Full-Width Single Image

A simple full-width image display that bleeds edge-to-edge across the viewport. Ideal for hero images, final renders, or any standalone visual that deserves maximum impact and attention without distractions.

Dev note: the full-bleed behavior comes from the .full-image class in style.css. Just swap the src with any 16:9 render.

Display Option 3
Image Grid (Side-by-Side)

The image grid displays multiple images side-by-side in a responsive layout. On desktop, images appear in rows; on mobile, they stack vertically. Perfect for showing variations, multiple angles, or related designs in a clean, organized format.

Dev note: the grid is controlled by .image-grid in style.css. On mobile, it intentionally collapses to one column. To force 2-up on phones, update the mobile media query for .image-grid.

Display Option 4
Full-Width Video

Full-width video players that automatically loop and can be controlled by visitors. On mobile, video controls are hidden initially and appear when tapped, creating a clean, cinematic presentation. Ideal for animations, motion graphics, or process videos.

Dev note: these videos are regular <video> tags inside .full-image. The “tap once to reveal controls” behavior on mobile comes from initMobileVideoControls() in scripts.js.

Display Option 5
Scroll-Driven 360° Video (Single)

This layout ties the playback of a 360° turntable (or any clip) to the user’s scroll position. As they scroll, the video scrubs smoothly from start to end, creating an interactive “spin-to-reveal” feel.

Display Option 7
Fade Slideshow with Auto-Play

This slideshow fades between images with automatic progression (6 seconds per slide). Visitors can manually navigate using left/right arrows that appear on hover. The slideshow loops infinitely and pauses when you hover over it. Great for showing a series of related images or process steps.

Dev notes:
• To change fade speed, edit .slideshow__image in style.css (e.g. transition: opacity 0.5s ease-in-out;).
• To change autoplay timing, update autoplayMs inside initSlideshows() in scripts.js.

Display Option 8
Sliding Slideshow with Auto-Bounce

This variant slides images horizontally (left to right) with smooth transitions. It auto-plays with a "bounce" effect—moving forward to the last image, then reversing back to the first, creating a seamless loop. Arrows are hidden at the ends. Use this for sequential narratives or progressive reveals where order matters.

Dev notes:
• This uses .slideshow slideshow--slide plus the physics-drag logic in initPhysicsDrag() inside scripts.js.
• Change slide speed by tweaking transition: transform 0.6s … on .slideshow--slide .slideshow__image in style.css.
